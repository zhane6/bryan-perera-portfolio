# Bryan Perera Portfolio

Premium dark/cinematic portfolio website for Bryan Perera.

## GitHub Pages
The repository contains a GitHub Pages deployment workflow. In GitHub, open **Settings → Pages** and choose **GitHub Actions** as the source if GitHub asks for a publishing source.

## Images
The current repository contains the complete site structure and intentional image placeholders. Add your portrait and portfolio work images later under `assets/` and replace the matching placeholder blocks in `index.html`.
